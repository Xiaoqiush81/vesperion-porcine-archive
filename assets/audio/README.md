# Sound effect sources

- `tarot-page-turn.mp3`: adapted from Mixkit's [“Big paper page turn”](https://mixkit.co/free-sound-effects/paper/) (item 1105) under the [Mixkit Sound Effects Free License](https://mixkit.co/license/#sfxFree). Normalized from the original WAV and encoded as a compact mono web asset.
- `theme-switch.mp3`: adapted from `switch34.wav` in Kenney UI Audio 1.0, released under CC0.

Both files were normalized and converted to 44.1 kHz mono MP3 for compact Safari and legacy-browser playback.
