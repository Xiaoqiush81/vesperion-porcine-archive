# Sound effect sources

- `tarot-card-lift.mp3`: adapted from OxidVideos' [“Taking playing card”](https://pixabay.com/sound-effects/film-special-effects-taking-playing-card-522520/) under the [Pixabay Content License](https://pixabay.com/service/license-summary/). It is a real single-card Foley recording, gently filtered and lowered for phone speakers.
- `theme-switch.mp3`: adapted from `switch34.wav` in Kenney UI Audio 1.0, released under CC0.

Both files were normalized and converted to 44.1 kHz mono MP3 for compact Safari and legacy-browser playback.
