# Sound effect sources

- `card-flip.mp3`: adapted from [“Card Flip” by f4ngy](https://freesound.org/s/240776/), licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Retrieved through kyperbelt/GGJ2024 and used as a short, compressed mono web asset.
- `theme-switch.mp3`: adapted from `switch34.wav` in Kenney UI Audio 1.0, released under CC0.

Both files were normalized and converted to 44.1 kHz mono MP3 for compact Safari and legacy-browser playback.
