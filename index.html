访问者可为浏览、娱乐与私人纪念使用本站；不得冒充首席会员、批量抓取后另行售卖馆藏，或以任何方式宣称自己比正版猪咪更可爱。后者将直接提交御享会员事务处复核。

DOCUMENT 03

《尊贵猪猪隐私与尾巴保护政策》

Private Data & Tail Protection Notice

一、本站主动收集什么

本站没有注册、登录、广告、分析统计或自建服务器数据库，也不会把鉴定答案、收藏、塔罗问题或占卜笔记主动发送给宅邸管理员。页面不会索取真实姓名、住址、联系方式或付款信息。

二、哪些内容保存在设备上

收藏的猪种与塔罗牌、近期猪种鉴定、已保存的占卜记录，以及主题、音乐、音效和音量偏好，会使用浏览器本地存储保留在当前设备与当前浏览器中。清除 Safari 网站数据、使用无痕浏览或更换设备后，这些内容可能消失，本站目前不提供云端同步或恢复。

三、托管平台数据

本站由 GitHub Pages 托管。访问 GitHub Pages 时，GitHub 可能为安全目的记录并保存访问者 IP 地址；相关处理由 GitHub 自身政策约束。详情可查阅 GitHub Pages 数据收集说明与 GitHub 隐私声明。

四、控制与删除

访问者可通过本站界面取消收藏；如需删除鉴定、占卜与偏好记录，可在浏览器设置中清除本网站数据。由于这些记录默认只存在本机，宅邸管理员通常无法查看、导出或代为删除它们。

五、尾巴特别条款

猪咪尾巴可自由展示、卷曲、摇晃或藏入被窝，不得因其形状受到歧视。Daddy 获得经猪方持续许可的轻触与观察权限；任何权限均不得被解释为可转让、永久不可撤回或适用于其他观察员。
