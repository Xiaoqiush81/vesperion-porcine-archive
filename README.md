> **Vesperion Porcine Archive · 维斯珀里昂猪类与异常现象图鉴**

一座持续生长的私人自然史宅邸，用于收录 Specimen №081 在日常生活、知识兔子洞与互联网深处留下的不同形态。现馆藏 **55 种猪咪形态**与一套完整的 **78 张《猪猪塔罗牌》**，并设有猪种鉴定所、宅邸档案室、猪事馆、抽牌桌及制度文件室。

**在线访问：** [xiaoqiush81.github.io/vesperion-porcine-archive](https://xiaoqiush81.github.io/vesperion-porcine-archive/)

## 馆舍导览

## 设计与体验

- **双色主题：** 象牙白与夜色主题均由语义化 CSS 变量驱动，组件不绑定固定颜色。
- **响应式宅邸：** 针对 iOS Safari、桌面浏览器和旧设备分别处理固定顶栏、安全区、触控与排版。
- **一致的内容层级：** 图鉴详情、猪事馆目录与卷宗均使用独立响应式布局，移动端纵向阅读，桌面端保留舒展留白。
- **渐进式图像加载：** 塔罗陈列优先加载轻量缩略图，打开详情时再载入高清牌面；关键资源会提前预热。
- **模块按需进入：** 图鉴、鉴定、塔罗、档案室与猪事馆仅在访问对应房间时加载，避免首屏承担整座馆舍的资源成本。
- **可分享房间路由：** 各馆舍使用 `?room=...` 地址，可直接打开并兼容早期 `#...` 链接。
- **完整浏览器图标：** 提供 ICO、16/32/48px 标签页图标、180px Apple Touch Icon 及 192/512px Web App 图标。
- **本地优先：** 收藏、鉴定记录、占卜记录、主题及声景偏好保存在当前浏览器，不依赖账户或远端数据库。
- **无构建运行：** 使用原生 HTML、CSS 与 ES Modules，可直接由静态服务器及 GitHub Pages 托管。

## 项目结构

```text
.
├── index.html                  # 馆舍结构、各房间与制度文件
├── favicon.ico                 # 桌面与旧版浏览器图标
├── site.webmanifest            # 可安装网页与多尺寸图标声明
├── assets/
│   ├── style.css               # 设计变量、响应式布局与双色主题
│   ├── cards/                  # 猪咪形态卡面
│   ├── tarot/                  # 78 张高清塔罗牌、牌背与轻量缩略图
│   ├── audio/                  # 翻牌、翻页及主题切换拟音
│   ├── icons/                  # 透明底浏览器图标套件
│   └── js/
│       ├── main.js             # 轻量入口、房间路由与按需加载
│       ├── archive.js          # 图鉴检索、筛选、随机捕猪与详情
│       ├── identity-*.js       # 鉴定题库、匹配引擎、界面与存储
│       ├── tarot-*.js          # 塔罗数据、抽牌引擎、界面与存储
│       ├── chronicles.js       # 猪事馆目录、分卷与折叠卷宗
│       ├── records.js          # 宅邸档案聚合
│       ├── archive-transfer.js # 本地档案导出、校验与原子恢复
│       ├── record-links.js     # 猪种—塔罗象征联结
│       ├── favorites.js        # 跨馆藏统一收藏状态
│       ├── audio.js            # Web Audio 声景、采样播放与混音
│       ├── site-assets.js      # 可选外部图标、音乐与音效入口
│       └── theme.js            # 主题切换与浏览器主题色同步
└── data/
    ├── specimens.json          # 猪咪馆藏的唯一数据源
    └── chronicles.json         # 猪事馆分区、分卷与记录数据
```

各模块通过清晰的单向职责协作：数据文件描述馆藏，纯逻辑引擎负责抽取与匹配，存储模块封装浏览器状态，界面模块只处理渲染和交互。新增形态、题目、牌阵或象征联结时，无需改动其他系统。

## 本地运行

本项目使用 ES Modules，需通过 HTTP 服务器访问：

```bash
python3 -m http.server 8080
```

然后打开 [http://localhost:8080](http://localhost:8080)。无需安装依赖或执行构建。

## 扩充馆藏

### 添加猪咪形态

1. 按现有结构向 `data/specimens.json` 追加记录。
2. 将对应 WebP 卡面放入 `assets/cards/`。
3. 保持档案 ID、卡面路径与分类字段唯一且一致。

页面会自动生成卡片、分类筛选、搜索索引与详情档案。若新形态需要参与鉴定或塔罗联动，再分别编辑 `assets/js/identity-data.js` 或 `assets/js/record-links.js`。

### 扩充鉴定题库

题目集中维护在 `assets/js/identity-data.js`。题库按观察维度分组，鉴定引擎会从不同维度随机抽题，并尽量避开上一轮题目；扩题不需要修改界面或匹配流程。

### 调整塔罗系统

- 牌面资料与牌阵：`assets/js/tarot-data.js`
- 洗牌、正逆位与补牌逻辑：`assets/js/tarot-engine.js`
- 占卜记录：`assets/js/tarot-storage.js`
- 塔罗交互界面：`assets/js/tarot.js`

### 整理猪事馆

公开卷宗集中维护在 `data/chronicles.json`，界面、分类切换、分卷和展开交互由 `assets/js/chronicles.js` 负责。新增记录只需归入对应馆藏与猪史分卷，不需要复制页面结构。

### 替换图标或声景资源

浏览器图标默认使用 `assets/icons/` 中的同源文件，以保证 Safari、Chrome、Edge 与 Firefox 的稳定读取。需要临时使用图床或自定义音乐、音效时，可在 `assets/js/site-assets.js` 中填写 HTTPS 地址；留空即沿用本地图标及内置声景。

## 数据与隐私

本站没有账户系统，也不会把鉴定答案、收藏、塔罗问题或笔记上传至宅邸服务器。业务数据默认仅存在当前浏览器的 `localStorage` 中；清理网站数据、更换浏览器、无痕会话结束或设备存储回收都可能使记录消失。

公开页面由 GitHub Pages 托管，字体由 Google Fonts 提供；相关基础设施仍可能依其自身政策处理完成网络请求所必需的技术信息。完整说明以站内“条款与政策”为准。

## 兼容性

- 优先支持当前版本的 Safari、Chrome、Edge 与 Firefox。
- 标签页、地址栏、Safari 历史记录、Apple Touch Icon 与 Web App Manifest 使用对应尺寸资源，不依赖运行时缩放同一张大图。
- iOS Safari 的音频必须由用户手势启动；切换后台后会按页面生命周期恢复或暂停。
- `localStorage`、Web Audio 或私密浏览限制不可用时，核心浏览功能仍可使用，相关偏好可能无法持久保存。
- 旧设备会先显示轻量资源并延后加载非当前房间模块，以减少首屏空白与解码压力。

## 部署

仓库使用 GitHub Pages。推送到 `main` 分支后，GitHub Actions 会自动发布静态站点；无需服务器、数据库或运行时密钥。

## 档案守则

- 核心编号始终为 `081`；其他字母与后缀表示同一标本的不同形态。
- 只记录已经观察到的猪咪现象，不得捏造不存在的罪名。
- 捕获率固定为 `0.00%`，但收藏不受此限制。
- 猪咪尾巴、耳朵、鼻头与蓬松程度均受宅邸制度文件保护。
